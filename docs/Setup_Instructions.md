# Setup Instructions

## JDK Version Used
- Tested with: **OpenJDK 21** (works with JDK 17+)

## Hello World (Quick Check)

1. Create `HelloWorld.java`:
```java
public class HelloWorld {
  public static void main(String[] args) {
    System.out.println("Hello World");
  }
}
```

2. Compile:
```bash
javac HelloWorld.java
```

3. Run:
```bash
java HelloWorld
```

If you see **Hello World**, your Java setup is correct.
